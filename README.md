## The line

> My plants only start dying the day I buy a watering can, like they were waiting for proof that I finally cared enough to kill them properly.

The setup is a frustration everyone with a houseplant knows: the plants
survive neglect for months. The punchline gives them a motive — they were
only waiting for proof that I finally cared, so they could die properly
now that it counts.

## How it works

`main.py` (pure Python 3.13 stdlib, no network) writes exactly that one
line, plus a trailing newline, to `/output/entry.txt`. The line is 140
characters, inside the 1–200 character gate.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
